## 香港 CN2 GIA 的线路强在哪？

一句话：到中国大陆三网直连，不绕公网。搬瓦工香港机房位于 Equinix HK2 数据中心，三条运营商线路的接入方式分别是：

- 中国电信：双向全程 CN2 GIA（AS4809），电信自己的精品网，拥塞时有优先权
- 中国联通：AS9929 高端专线接入

三网都直连，意味着不管你的宽带是哪家，晚高峰都不用和国际出口挤独木桥。硬件层面，这批香港机器目前是 AMD EPYC 处理器加 NVMe SSD RAID-10 阵列，IO 性能对数据库和高并发应用都够用。
